介绍

Vue (发音为 /vjuː/，类似 view) 是一款用于构建用户界面的 JavaScript 框架。

官网

Vue.js

playground

使用

cdn 引入


<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script>
    const app = Vue.createApp({})
    app.mount('#app')
</script>
<div id="app">
    <div>Hello Vue 3.0!</div>
</div>

下载下来后本地引入


<script src="./vue.global.js"></script>
<script>

npm 引入 vue (或者说安装 vue)

npm install vue@next

使用 vue-cli 创建项目

npm install -g @vue/cli
vue create my-project

名词解释：

  • 框架：是一套完整的解决方案，它包括了前端开发的所有阶段，包括设计、编码、测试等。
  • 渐进式框架：是指在开发过程中，可以逐步地添加新的功能，而不需要重新构建整个框架。
  • 声明式框架：是指在开发过程中，可以声明式地描述界面，而不需要手动地编写具体的代码。
  • 回流和重绘: 当元素的几何信息发生变化时，浏览器需要重新计算元素的位置和大小，这个过程叫回流, 重绘：当元素的外观发生变化，但不影响布局时，浏览器只需要重新绘制这个元素
